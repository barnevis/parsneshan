# ویژگی احتیاط

## نام

`caution` — افزونهٔ بلوک احتیاط

## هدف

فراهم کردن یک بلوک احتیاط در Markdown برای محتوای فارسی؛ ساختار آن مشابه ویژگی [هشدار](warning.md) است و تفاوت تنها در معنای نوع بلوک است.

## syntax

```markdown
... احتیاط
متن احتیاط
...
```

* خط آغازین از سه نقطهٔ `.` پشت سر هم، سپس فضای اختیاری و سپس واژهٔ دقیق `احتیاط` تشکیل می‌شود.
* خط پایانی باید دقیقاً سه نقطهٔ `.` و فقط فضای اختیاری باشد.
* محتوای بین این دو خط، بخشی از احتیاط است.

## استفاده

```js
import {micromark} from 'micromark'
import {caution, cautionHtml} from 'parsneshan'

const html = micromark('... احتیاط\nمتن **مهم**\n...\n', {
  extensions: [caution()],
  htmlExtensions: [cautionHtml()]
})
```

## خروجی مورد انتظار

```html
<div class="parsneshan-caution">
<p>متن <strong>مهم</strong></p>
</div>
```

* کل بلوک درون `<div class="parsneshan-caution">` قرار می‌گیرد.
* محتوای داخلی همانند یک سند Markdown معمولی پردازش می‌شود؛ بنابراین عناصر استاندارد مانند پاراگراف، لیست، عنوان، blockquote و تأکید درون بلوک کار می‌کنند.

## محدودیت‌ها

* واژهٔ نوع باید دقیقاً `احتیاط` باشد؛ نوشتن متن دیگری پس از `...` (مانند `... احتیاط خانه`) باعث می‌شود خط به‌صورت متن معمولی پردازش شود.
* فقط `...` با سه نقطه مجاز است؛ تعداد بیشتر یا کمتر نقطه در خط آغازین، بلوک ایجاد نمی‌کند.
* خط پایانی باید دقیقاً سه نقطه باشد؛ کمتر یا بیشتر بودن تعداد نقاط، بلوک را نمی‌بندد.
* اگر خط پایانی چیزی غیر از فاصله داشته باشد (مانند `... اضافه`)، بلوک بسته نمی‌شود.
* **تودرتو:** تودرتوی بلوک احتیاط پشتیبانی نمی‌شود و رفتار آن تعریف‌نشده است؛ از قرار دادن خط `... احتیاط` درون محتوای بلوک پرهیز شود.

## سازگاری با Markdown استاندارد

* بدون فعال بودن افزونه، `... احتیاط` به‌صورت یک پاراگراف معمولی رندر می‌شود و رفتاری تغییر نمی‌کند.
* تورفتگی چهار فاصله یا tab باعث می‌شود خط به‌صورت کد تورفته (indented code) پردازش شود، مطابق استاندارد.
* تا سه فاصله تورفتگی در هر سه خط (آغازین، پایانی و محتوا) مجاز است.
* بلوک احتیاط می‌تواند پاراگراف باز را قطع کند (مشابه رفتار heading).

## حالت‌های خاص

* **بلوک بسته‌نشده:** اگر خط پایانی نیاید، بلوک تا انتهای سند ادامه می‌یابد (مشابه رفتار fenced code بسته‌نشده).
* **بدون فاصله پس از نقاط:** `...احتیاط` نیز بلوک ایجاد می‌کند.
* **درون blockquote:** با پیشوند `>` در همهٔ خطوط، بلوک احتیاط درون نقل قول کار می‌کند.
* **خطوط خالی:** خطوط خالی درون بلوک مجازند و مرز بین بخش‌های محتوا هستند.
* **همزیستی با سایر انواع:** این افزونه همراه افزونهٔ هشدار قابل استفاده است و بر آن اثری ندارد؛ هر واژهٔ نوع فقط بلوک خودش را ایجاد می‌کند.
