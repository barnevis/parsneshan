# قابلیت نکته

## نام

`note` — افزونهٔ بلوک نکته

## هدف

فراهم کردن یک بلوک نکته در Markdown برای محتوای فارسی؛ ساختار آن مشابه قابلیت‌های [هشدار](warning.md)، [احتیاط](caution.md)، [مهم](important.md) و [راهنما](tip.md) است و تفاوت تنها در معنای نوع بلوک است.

## syntax

```markdown
... نکته
متن نکته
...
```

* خط آغازین از سه نقطهٔ `.` پشت سر هم، سپس فضای اختیاری و سپس واژهٔ دقیق `نکته` تشکیل می‌شود.
* خط پایانی باید دقیقاً سه نقطهٔ `.` و فقط فضای اختیاری باشد.
* محتوای بین این دو خط، بخشی از نکته است.

## استفاده

```js
import {micromark} from 'micromark'
import {note, noteHtml} from 'parsneshan'

const html = micromark('... نکته\nمتن **مهم**\n...\n', {
  extensions: [note()],
  htmlExtensions: [noteHtml()]
})
```

## خروجی مورد انتظار

```html
<div class="parsneshan-note">
<p>متن <strong>مهم</strong></p>
</div>
```

* کل بلوک درون `<div class="parsneshan-note">` قرار می‌گیرد.
* محتوای داخلی همانند یک سند Markdown معمولی پردازش می‌شود؛ بنابراین عناصر استاندارد مانند پاراگراف، لیست، عنوان، blockquote و تأکید درون بلوک کار می‌کنند.

## محدودیت‌ها

* واژهٔ نوع باید دقیقاً `نکته` باشد؛ نوشتن متن دیگری پس از `...` (مانند `... نکته خانه`) باعث می‌شود خط به‌صورت متن معمولی پردازش شود.
* فقط `...` با سه نقطه مجاز است؛ تعداد بیشتر یا کمتر نقطه در خط آغازین، بلوک ایجاد نمی‌کند.
* خط پایانی باید دقیقاً سه نقطه باشد؛ کمتر یا بیشتر بودن تعداد نقاط، بلوک را نمی‌بندد.
* اگر خط پایانی چیزی غیر از فاصله داشته باشد (مانند `... اضافه`)، بلوک بسته نمی‌شود.
* **تودرتو:** تودرتوی بلوک نکته پشتیبانی نمی‌شود و رفتار آن تعریف‌نشده است؛ از قرار دادن خط `... نکته` درون محتوای بلوک پرهیز شود.

## سازگاری با Markdown استاندارد

* بدون فعال بودن افزونه، `... نکته` به‌صورت یک پاراگراف معمولی رندر می‌شود و رفتاری تغییر نمی‌کند.
* تورفتگی چهار فاصله یا tab باعث می‌شود خط به‌صورت کد تورفته (indented code) پردازش شود، مطابق استاندارد.
* تا سه فاصله تورفتگی در هر سه خط (آغازین، پایانی و محتوا) مجاز است.
* بلوک نکته می‌تواند پاراگراف باز را قطع کند (مشابه رفتار heading).

## حالت‌های خاص

* **بلوک بسته‌نشده:** اگر خط پایانی نیاید، بلوک تا انتهای سند ادامه می‌یابد (مشابه رفتار fenced code بسته‌نشده).
* **بدون فاصله پس از نقاط:** `...نکته` نیز بلوک ایجاد می‌کند.
* **درون blockquote:** با پیشوند `>` در همهٔ خطوط، بلوک نکته درون نقل قول کار می‌کند.
* **خطوط خالی:** خطوط خالی درون بلوک مجازند و مرز بین بخش‌های محتوا هستند.
* **همزیستی با سایر انواع:** این افزونه همراه افزونه‌های هشدار، احتیاط، مهم و راهنما قابل استفاده است و بر آن‌ها اثری ندارد؛ هر واژهٔ نوع فقط بلوک خودش را ایجاد می‌کند.
