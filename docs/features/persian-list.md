# قابلیت لیست عددی فارسی

## نام

`persian-list` — افزونهٔ لیست مرتب با ارقام فارسی

## هدف

فراهم کردن لیست مرتب (ordered list) با ارقام فارسی در Markdown، مطابق قاعدهٔ لیست عددی CommonMark ولی با نشانه‌گذاری بومی:

```markdown
۱. الف
۲. ب
۳. ج
```

## syntax

* نشانه‌گذار عددی: یک تا نه رقم فارسی (`۰` تا `۹`، یعنی U+06F0 تا U+06F9) و سپس نقطه `.` یا پرانتز بسته `)`.
* **ارقام عربی (٠ تا ٩، U+0660 تا U+0669) پشتیبانی نمی‌شوند** و به‌صورت متن معمولی رندر می‌شوند.
* فقط عدد `۱` می‌تواند پاراگراف باز را قطع کند (مشابه قاعدهٔ CommonMark که در آن فقط `1.` چنین اجازه‌ای دارد).
* حداکثر نُه رقم در عدد مجاز است (مطابق سقف CommonMark).
* عدد اولین آیتم به attribute `start` لیست خروجی `<ol>` می‌رود؛ اگر `۱` باشد، `start` emitting نمی‌شود.

## استفاده

```js
import {micromark} from 'micromark'
import {persianListExtension, persianListHtml} from 'parsneshan/extensions/persian-list'

const html = micromark('۱. الف\n۲. ب\n', {
  extensions: [persianListExtension()],
  htmlExtensions: [persianListHtml()]
})
```

## خروجی مورد انتظار

```html
<ol>
<li>الف</li>
<li>ب</li>
</ol>
```

شروع از عدد دیگر:

```markdown
۲. الف
۳. ب
```

```html
<ol start="2">
<li>الف</li>
<li>ب</li>
</ol>
```

* خروجی همان لیست استاندارد `<ol>`/`<li>` است؛ لیست loose/tight، خطوط خالی، ادامهٔ خط با تورفتگی و lazy continuation همگی مطابق CommonMark کار می‌کنند.
* لیست می‌تواند تودرتو شود و درون blockquote و بلوک‌های دیگر (مانند هشدار) کار کند.

## محدودیت‌ها

* ارقام فارسی و ASCII در یک لیست با هم مخلوط نمی‌شوند: `۱.` و `2.` دو لیست جدا هستند.
* نشانه‌گذار (`.` یا `)`) در تمام آیتم‌های یک لیست باید یکسان باشد.
* عدد بدون نشانه‌گذار (`۱۲ الف`) لیست نیست.

## سازگاری با Markdown استاندارد

* بدون فعال بودن افزونه، ارقام فارسی بخشی از پاراگراف معمولی هستند و رفتاری تغییر نمی‌کند.
* لیست‌های ASCII (`1.`، `2.`) و لیست‌های نامرتب (`-`، `*`، `+`) کاملاً بدون تغییر کار می‌کنند.
* تورفتگی چهار فاصله یا tab مطابق استاندارد، کد تورفته محسوب می‌شود نه لیست.
* افزودنی‌های این افزونه به لیست‌های ASCII صفر است؛ تنها نکته این است که هندلر `start` با این افزونه هر دو دسته رقم را می‌شناسد (که سازگار با رفتار پیش‌فرض است).
