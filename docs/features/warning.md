# قابلیت هشدار

## نام

`warning` — افزونهٔ بلوک هشدار

## هدف

فراهم کردن یک بلوک هشدار در Markdown برای محتوای فارسی. این قابلیت معادل ساختارهایی مانند admonition در سایر ابزارهاست و امکان مشخص بودن معنایی بخش‌های هشداردهندهٔ متن را فراهم می‌کند.

## syntax

```markdown
... هشدار
متن هشدار
...
```

* خط آغازین از سه نقطهٔ `.` پشت سر هم، سپس فضای اختیاری و سپس واژهٔ دقیق `هشدار` تشکیل می‌شود.
* خط پایانی تنها شامل سه نقطهٔ `.` و فضای اختیاری است.
* محتوای بین این دو خط، بخشی از هشدار است.

## استفاده

```js
import {micromark} from 'micromark'
import {warning, warningHtml} from 'parsneshan'

const html = micromark('... هشدار\nمتن **مهم**\n...\n', {
  extensions: [warning()],
  htmlExtensions: [warningHtml()]
})
```

## خروجی مورد انتظار

```html
<div class="parsneshan-warning">
<p>متن <strong>مهم</strong></p>
</div>
```

* کل بلوک درون `<div class="parsneshan-warning">` قرار می‌گیرد.
* محتوای داخلی همانند یک سند Markdown معمولی پردازش می‌شود؛ بنابراین عناصر استاندارد مانند پاراگراف، لیست، عنوان، blockquote و تأکید درون بلوک کار می‌کنند.

## محدودیت‌ها

* واژهٔ نوع باید دقیقاً `هشدار` باشد؛ نوشتن متن دیگری پس از `...` (مانند `... هشدار خانه`) باعث می‌شود خط به‌صورت متن معمولی پردازش شود.
* فقط `...` با سه نقطه مجاز است؛ تعداد بیشتر یا کمتر نقطه در خط آغازین، بلوک ایجاد نمی‌کند.
* خط پایانی با سه نقطه یا بیشتر (مانند `....`) بلوک را می‌بندد؛ کمتر از سه نقطه بلوک را نمی‌بندد.
* اگر خط پایانی چیزی غیر از فاصله داشته باشد (مانند `... اضافه`)، بلوک بسته نمی‌شود.
* **تودرتو:** یک خط `... هشدار` درون محتوای بلوک، بلوک بیرونی را نمی‌بندد و بلوک تودرتوی جدیدی باز می‌کند؛ اما مرز بسته‌شدن بلوک بیرونی در این حالت مشخص و قابل اتکا نیست. تا زمان تعریف دقیق رفتار تودرتو، از آن پرهیز شود.

## سازگاری با Markdown استاندارد

* بدون فعال بودن افزونه، `... هشدار` به‌صورت یک پاراگراف معمولی رندر می‌شود و رفتاری تغییر نمی‌کند.
* `...` تنها در ابتدای خط در Markdown استاندارد construct خاصی نیست (thematic break نیست)، بنابراین تداخل واقعی وجود ندارد؛ تنها متن‌های پاراگرافی که با `... هشدار` آغاز می‌شوند با فعال بودن افزونه معنای جدید می‌گیرند.
* تورفتگی چهار فاصله یا tab باعث می‌شود خط به‌صورت کد تورفته (indented code) پردازش شود، مطابق استاندارد.
* تا سه فاصله تورفتگی در هر سه خط (آغازین، پایانی و محتوا) مجاز است.
* بلوک هشدار می‌تواند پاراگراف باز را قطع کند (مشابه رفتار heading).

## حالت‌های خاص

* **بلوک بسته‌نشده:** اگر خط پایانی نیاید، بلوک تا انتهای سند ادامه می‌یابد (مشابه رفتار fenced code بسته‌نشده).
* **بدون فاصله پس از نقاط:** `...هشدار` نیز بلوک ایجاد می‌کند.
* **درون blockquote:** با پیشوند `>` در همهٔ خطوط، بلوک هشدار درون نقل قول کار می‌کند.
* **خطوط خالی:** خطوط خالی درون بلوک مجازند و مرز بین بخش‌های محتوا هستند.
