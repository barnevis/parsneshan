# قابلیت لیست مرتب با ارقام فارسی

## نام

`persianOrderedList` — افزونهٔ لیست مرتب با ارقام فارسی

## هدف

فراهم کردن پشتیبانی از لیست‌های مرتب با ارقام فارسی (`۰۱۲۳۴۵۶۷۸۹`) در Markdown، با رفتار کاملاً مطابق با لیست‌های مرتب استاندارد CommonMark.

## Syntax

```markdown
۱. مورد اول
۲. مورد دوم
۳. مورد سوم
```

یا با پرانتز:

```markdown
۱) مورد اول
۲) مورد دوم
۳) مورد سوم
```

* **خط آغازین:** عدد فارسی یک یا چند رقمی (`۰`–`۹`)، سپس `.` یا `)`، سپس فضای اختیاری.
* **شماره شروع:** از اولین عدد لیست استخراج شده و در attribute `start` تگ `<ol>` گنجانده می‌شود.
* **محتوا:** هرچه در آیتم‌های لیست باشد، به‌صورت Markdown معمولی پردازش می‌شود.

## استفاده

```js
import {micromark} from 'micromark'
import {persianOrderedList, persianOrderedListHtml} from 'parsneshan'

const html = micromark('۱. اول\n۲. دوم\n۳. سوم\n', {
  extensions: [persianOrderedList()],
  htmlExtensions: [persianOrderedListHtml()]
})
```

## خروجی مورد انتظار

```html
<ol>
<li>اول</li>
<li>دوم</li>
<li>سوم</li>
</ol>
```

اگر لیست با عددی غیر از ۱ آغاز شود:

```html
<ol start="5">
<li>پنجم</li>
<li>ششم</li>
</ol>
```

## محدودیت‌ها

* **تورفتگی:** تا سه فاصله مجاز است؛ چهار فاصله یا tab طبق استاندارد، کد تورفته محسوب می‌شود نه لیست.
* **شماره‌گذاری:** فقط ارقام فارسی (`۰`–`۹`) پشتیبانی می‌شوند؛ ارقام انگلیسی به‌صورت پیش‌فرض کار می‌کنند.
* **Markers:** هر دو `.` و `)` پشتیبانی می‌شوند.
* **تورفتگی لیست:** پشتیبانی اولیه؛ تو در تو شدن لیست‌ها محدودیت‌هایی دارد.
* **قطع پاراگراف:** خط آغازین می‌تواند پاراگراف باز را قطع کند (مشابه heading).

## سازگاری با Markdown chuẩn

* ارقام انگلیسی (`1.`، `2.`، ...) به‌صورت پیش‌فرض کار می‌کنند و رفتارشان تغییر نمی‌کند.
* ارقام فارسی فقط در صورت فعال بودن این افزونه پردازش می‌شوند.
* ترکیب با سایر افزونه‌های پارس‌نشان (هشدار، احتیاط، مهم، راهنما، نکته) بدون تداخل کار می‌کند.
* سازگاری با `blockquote`، `code block`، `thematic break` و سایر ساختارهای استاندارد.

## حالت‌های خاص

* **چندرقمی بودن:** اعداد چند رقمی (مثل `۱۰.`) کاملاً پشتیبانی می‌شوند.
* **فاصله‌گذاری:** فاصله پس از marker اختیاری است (`۱.مورد` و `۱. مورد` هر دو کار می‌کنند).
* **Tab بعد از marker:** پشتیبانی می‌شود (`۱.\tمورد`).
* **خالی بودن آیتم:** آیتم‌های خالی مجازند.
* **ترکیب با کد/blockquote در آیتم:** پشتیبانی می‌شود.
