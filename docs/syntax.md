# syntax افزونه‌های پارس‌نشان

این سند syntax ویژگی‌های اضافه‌شدهٔ پارس‌نشان و روش استفاده از آن‌ها در متن Markdown را مستند می‌کند.

## الگوی مشترک بلوک‌ها

پنج قابلیت فعلی از یک الگوی مشترک استفاده می‌کنند:

```markdown
... نوع
محتوا
...
```

* **خط آغازین:** سه نقطهٔ `.`، سپس فضای اختیاری، سپس واژهٔ نوع. واژهٔ نوع باید دقیقاً مطابق جدول زیر باشد؛ متن اضافه پس از آن بلوک را باطل می‌کند.
* **خط پایانی:** دقیقاً سه نقطهٔ `.` و فقط فضای اختیاری.
* **محتوا:** هرچه بین دو fence باشد، به‌صورت یک سند Markdown معمولی پردازش می‌شود؛ بنابراین پاراگراف، عنوان، لیست، blockquote، تأکید و سایر عناصر استاندارد درون بلوک کار می‌کنند.

## انواع فعال

| خط آغازین | خروجی HTML |
|---|---|
| `... هشدار` | `<div class="parsneshan-warning">` |
| `... احتیاط` | `<div class="parsneshan-caution">` |
| `... مهم` | `<div class="parsneshan-important">` |
| `... راهنما` | `<div class="parsneshan-tip">` |
| `... نکته` | `<div class="parsneshan-note">` |

هر نوع فقط با واژهٔ خودش ایجاد می‌شود؛ فعال‌سازی هم‌زمان چند افزونه بدون تداخل است.

## نمونهٔ کامل

ورودی:

```markdown
... هشدار
مسیر زیر **بسته** است.

- مورد یک
- مورد دو
...
```

خروجی:

```html
<div class="parsneshan-warning">
<p>مسیر زیر <strong>بسته</strong> است.</p>
<ul>
<li>مورد یک</li>
<li>مورد دو</li>
</ul>
</div>
```

## قواعد و مرزها

* **تورفتگی:** تا سه فاصله مجاز است؛ چهار فاصله یا tab طبق استاندارد، کد تورفته محسوب می‌شود نه بلوک.
* **قطع پاراگراف:** خط آغازین می‌تواند پاراگراف باز را قطع کند (مانند heading).
* **بلوک بسته‌نشده:** اگر خط پایانی نیاید، بلوک تا انتهای سند ادامه می‌یابد.
* **خطوط خالی:** درون بلوک مجازند و بخشی از محتوا هستند.
* **درون blockquote:** با پیشوند `>` در همهٔ خطوط کار می‌کند.
* **بدون fence آغازین معتبر:** اگر نقاط کمتر/بیشتر از سه باشد یا واژهٔ نوع ناقص باشد، خط به‌صورت متن معمولی پردازش می‌شود.
* **تودرتو:** پشتیبانی نمی‌شود و رفتار آن تعریف‌نشده است؛ از قرار دادن `... <نوع>` درون محتوای بلوک پرهیز شود.

## سازگاری با Markdown استاندارد

`...` در ابتدای خط در CommonMark construct خاصی نیست (thematic break نیست)، بنابراین تداخل ساختاری وجود ندارد؛ تنها اثر جانبی این است که پاراگراف‌هایی که اتفاقاً با `... هشدار` (یا انواع دیگر) آغاز شوند، با فعال بودن افزونه معنای جدید می‌گیرند. بدون افزونه، رفتار کاملاً استاندارد است.
